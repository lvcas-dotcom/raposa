# Preparação para aprovação do commit

## O que a análise mediu

O README aponta para o ícone e banner novos, preservados em arquivos v2.
As duas imagens anteriores têm alterações locais do mantenedor e serão mantidas
fora do stage desta proposta. O remoto foi consultado antes da preparação.

## Decisões

- [usuário] Preparar o commit sem coautoria e aguardar sua aprovação.
- Incluir README, dois novos assets e registros desta issue.
- Mensagem proposta: `feat(brand): adotar mascote original do Open Rabbit`.
- Sem trailer de coautoria e sem referência a uma issue remota inexistente.

## Guardrails

Preparar somente o stage nesta passada. Criar o commit e fazer push dependem da
aprovação solicitada pelo mantenedor. Não descartar nem incluir as alterações
locais das imagens anteriores. Não modificar código de runtime.
