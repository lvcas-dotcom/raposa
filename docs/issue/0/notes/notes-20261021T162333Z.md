# Direção pública do projeto

## O que a análise mediu

O projeto estava sem remoto e sem commits. A preparação inicial de CI precisava
ser ajustada ao destino público escolhido. A execução local de moon encontra
a limitação conhecida de repositório com HEAD ainda inexistente.

## Decisões

- [usuário] Projeto pessoal open source, hospedado no GitHub, sem vínculo corporativo.
- [usuário] Nenhuma citação a projetos internos, inclusive em registros ignorados.
- [usuário] Avisar quando estiver pronto para montar os commits juntos; sem coautoria.
- GitHub Actions para validação em PR, push em main e execução manual.
- Actions fixadas em SHAs dos tags oficiais consultados em 2026-10-21:
  checkout v7.0.1 `3d3c42e5aac5ba805825da76410c181273ba90b1`;
  setup-go v7.0.0 `b7ad1dad31e06c5925ef5d2fc7ad053ef454303e`.
- Licença e provedor/modelo ainda aguardam escolha do mantenedor.

## Guardrails

Não publicar, criar remoto, commit, push ou PR nesta passada. Documentação
portável e fontes públicas apenas. Não adicionar código, caminhos ou identidades
de outros projetos. Validação local não será descrita como execução da CI remota.
