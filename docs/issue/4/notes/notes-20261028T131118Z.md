# Diff numerado e janela de contexto

## O que a análise mediu

- `Instructions` pede `Linha` e `Trecho` literal, mas `change` só traz `Depois` cru.
- `Achado.Validate` exige trecho exato a partir da linha; contagem errada descarta.
- O bridge envia `stream:false` e `format:json`, sem `options.num_ctx`.
- Contrato do Ollama consultado: `truncate:false` e `shift:false` fazem o servidor
  devolver 400 para prompt acima da janela, em vez de descartar mensagens.
- Nenhum modelo real foi executado; o ganho em candidatos aceitos é hipótese.

## Decisões

- [usuário] Recorte: diff numerado e janela de contexto antes da recuperação por símbolos.
- [usuário] Campo aditivo no protocolo v1, sem v2.
- `Alteradas` e o diff numerado saem de um único `git diff --unified=3`.
- `--num-ctx` obrigatório no bridge, sem default implícito, como `--model`.
- Segunda barreira: `prompt_eval_count + eval_count >= num_ctx` é erro.

## Guardrails

Não executar código do alvo. Não alterar formato de resposta nem `Validate`.
Diff numerado conta no orçamento de 2 MiB. Alterações da issue 3 no working
tree são preservadas; sem staging, commit ou push.
